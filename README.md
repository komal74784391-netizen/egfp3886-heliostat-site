# Heliostat Computational Learning Lab - Website

Source repository for the Heliostat Computational Learning Lab public website.

- `_publications/` contains one markdown file per publication
- each entry uses YAML front matter with `title`, `venue`, `status`, and an
  optional `codeurl` that the archive template renders as the "Code" link
- `status` records the last known state of the paper and may lag behind the
  acceptance notices that arrive by email
- static build configuration lives in `_config.yml`
